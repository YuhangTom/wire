# Subsampled dataset of wire cuts

This dataset is a subsampled version of the original `x3p` wire cuts
data. The subsampling is performed at a factor of 10.

## Usage

``` r
x3p_subsamples
```

## Format

A list of `x3p` objects, each representing a surface scan. The list
includes:

- T1AW-LI-R1: An `x3p` object representing the first surface scan.

- T1AW-LI-R2: An `x3p` object representing the second surface scan.
